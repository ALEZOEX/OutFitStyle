## 🏗️ ТЕКУЩАЯ АРХИТЕКТУРА

### Принцип работы

```
┌─────────────────────────────────────────────────────────┐
│                    Firebase Auth                        │
│  (единая система авторизации с марта 2026)             │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│                  SessionManager                         │
│  - Управление сессией через FirebaseAuth               │
│  - Сохранение состояния в SharedPreferences            │
│  - Stream authStateChanges для реактивности            │
└─────────────────────────────────────────────────────────┘
                          │
        ┌─────────────────┼─────────────────┐
        ▼                 ▼                 ▼
┌───────────────┐ ┌───────────────┐ ┌───────────────┐
│  AuthScreen   │ │   AuthGate    │ │ ProfileScreen │
│  (вход/рег)   │ │ (startup flow)│ │   (logout)    │
└───────────────┘ └───────────────┘ └───────────────┘
```

### Ключевые изменения

| Было (JWT) | Стало (Firebase) |
|------------|------------------|
| Access token в памяти/cookie | Firebase ID token |
| Refresh token в httpOnly cookie | Firebase refresh token (внутри SDK) |
| Ручной refresh через `/api/v1/auth/refresh` | Автоматический refresh в Firebase SDK |
| `AuthRepository.login()` | `SessionManager.signIn()` |
| `AuthService.loginWithGoogle()` | `SessionManager.signInWithGoogle()` |

### 1. SessionManager (ЯДРО СИСТЕМЫ)

**Файл:** `client/lib/src/auth/session_manager.dart`  
**Строк:** 379  
**Назначение:** Единый центр управления авторизацией через Firebase Auth

**Основные методы:**
```dart
class SessionManager {
  // Вход по email/password
  Future<bool> signIn({required String email, required String password});
  
  // Регистрация
  Future<bool> signUp(String email, String password, String displayName);
  
  // Вход через Google
  Future<bool> signInWithGoogle();
  
  // Выход
  Future<void> signOut();
  
  // Сброс пароля
  Future<void> resetPassword(String email);
  
  // Обновление профиля
  Future<void> updateUserProfile({String? displayName, String? photoURL});
  
  // Отправка письма подтверждения
  Future<void> sendEmailVerification();
  
  // Поток состояния авторизации
  Stream<bool> get authStateChanges;
  
  // Текущий пользователь
  User? get currentUser;
  String? get currentUserId;
  bool get isAuthenticated;
}
```

**Исправления (Март 2026):**
- ✅ Race condition в `_setupAuthStateListener()` — использует `_authStateChanges` getter
- ✅ `Future.delayed(100ms)` заменён на `firstWhere` + `timeout(5s)`
- ✅ StreamSubscription сохраняется и отменяется в `dispose()`
- ✅ Добавлен публичный getter `authStateChanges`

### 2. Session Provider

**Файл:** `client/lib/src/presentation/providers/session_provider.dart`  
**Строк:** 63  
**Назначение:** Riverpod провайдеры для SessionManager

**Провайдеры:**
```dart
// Инициализация SharedPreferences
final sharedPreferencesProvider = FutureProvider<SharedPreferences>((ref) async {
  return await SharedPreferences.getInstance();
});

// SessionManager (единый экземпляр)
final sessionManagerProvider = FutureProvider<SessionManager>((ref) async {
  final firebaseAuth = FirebaseAuth.instance;
  final sharedPreferences = await ref.watch(sharedPreferencesProvider.future);
  return SessionManager(firebaseAuth, sharedPreferences);
});

// Состояние авторизации (Stream<bool>)
final authStateProvider = StreamProvider<bool>((ref) {
  final sessionManager = await ref.watch(sessionManagerProvider.future);
  return sessionManager.authStateChanges;
});
```

### 3. Auth Gate

**Файл:** `client/lib/src/presentation/app/auth_gate.dart`  
**Строк:** 128  
**Назначение:** Контролирует startup flow приложения

**Flow:**
```dart
1. Firebase Auth автоматически управляет сессией
2. Подписка на authStateChanges из SessionManager
3. При авторизации → запуск notifications polling
4. При разавторизации → остановка polling
```

**Исправления:**
- ✅ Убран `Scaffold` без `MaterialApp` (возвращает `Center + CircularProgressIndicator`)
- ✅ Убран `refreshToken()` (не нужен для Firebase)
- ✅ Подписка на `authStateChanges` с правильной очисткой в `dispose()`

// БЫЛО (JWT):
final authService = AuthService(...);

await context.go('/home'); // ручная навигация
