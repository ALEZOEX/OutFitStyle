## 🌟 Обзор

OutfitStyle - это передовая платформа рекомендаций моды, которая предлагает идеальный наряд на основе погодных условий, личных предпочтений в стиле и случая. Платформа сочетает алгоритмы машинного обучения с данными о текущей погоде, чтобы предоставлять персонализированные рекомендации по нарядам.

### ✨ Ключевые особенности
- **Рекомендации на основе погоды**: Получайте предложения нарядов на основе текущей погоды
- **Персонализированные предпочтения**: Настройте рекомендации в соответствии со своим стилем
- **Управление гардеробом**: Добавляйте и управляйте своими предметами одежды
- **На основе машинного обучения**: Алгоритм подбора нарядов с использованием ИИ
- **Поддержка офлайн**: Работает без подключения к интернету
- **Кроссплатформенность**: Доступно на iOS и Android
- **Флаги функций**: A/B тестирование и постепенные запуски
- **Push-уведомления**: Оповещения о погоде и рекомендациях
- **Аналитика и отчеты о сбоях**: Интеграция Firebase

### Технологический стек

#### Сервисы бэкенда
- **Язык**: Go 1.21+
- **Фреймворк**: net/http + пользовательские промежуточные слои
- **База данных**: PostgreSQL
- **Кэширование**: Redis
- **Сервис ML**: Python (FastAPI, CatBoost)
- **Метрики**: Prometheus
- **Журналирование**: Zap (структурированное журналирование)
- **Сообщения**: Apache Kafka
- **Service Mesh**: Istio

#### Приложение фронтенда
- **Фреймворк**: Flutter
- **Управление состоянием**: Riverpod
- **Навигация**: Go Router
- **База данных**: Drift (SQLite)
- **Сетевые технологии**: Dio + Retrofit
- **Аналитика**: Firebase Analytics
- **Отчеты о сбоях**: Firebase Crashlytics

#### Инфраструктура
- **Контейнеризация**: Docker
- **Развертывание**: Docker Compose / Kubernetes
- **Мониторинг**: Prometheus + Grafana
- **Журналирование**: Zap (структурированное журналирование)
- **CI/CD**: GitHub Actions
- **Безопасность**: HashiCorp Vault (рекомендуется)

## 🚀 Быстрый старт

### Предварительные требования
- Go 1.21+ для разработки бэкенда
- Flutter SDK 3.16+ для разработки фронтенда
- Python 3.11+ для сервиса ML
- Docker & Docker Compose для контейнеризации
- Git для контроля версий

### Настройка локальной разработки

1. **Клонируйте репозиторий**
```bash
git clone https://github.com/your-org/outfitstyle.git
cd outfitstyle
```

2. **Настройте переменные среды**
```bash
cp .env.example .env
# Отредактируйте .env с вашими ключами API и учетными данными базы данных
```

3. **Запустите службы с помощью Docker Compose**
```bash
docker-compose up -d
```

4. **Для разработки фронтенда**
```bash
cd client
flutter pub get
flutter run
```

5. **Для разработки бэкенда**
```bash
cd server
go run cmd/server/main.go
```

### Развертывание в продакшене
```bash
# Собрать и развернуть с помощью Docker Compose
docker-compose -f docker-compose.prod.yml up -d
```

## 📊 Мониторинг и наблюдаемость

### Три столпа
- **Метрики**: Prometheus для количественных измерений
- **Журналы**: Структурированное журналирование с Zap
- **Трассировки**: Распределенная трассировка с OpenTelemetry

### Ключевые метрики
- **Система**: ЦП, память, диск, сеть
- **Приложение**: Время ответа, частота ошибок, пропускная способность
- **Service Mesh**: Запросы между сервисами, время отклика, процент ошибок
- **Сообщения**: Задержка в обработке, количество событий, ошибки обработки
- **Бизнес**: DAU, коэффициенты конверсии, использование функций

## 🔐 Безопасность

### Аутентификация и авторизация
- Токены JWT с алгоритмом RS256
- OAuth 2.0 с входом через Google (Firebase Auth для Web, google_sign_in для Mobile)
- Refresh токены с автоматическим обновлением (Access: 1 час, Refresh: 90 дней)
- Ограничение скорости на пользователя/IP
- Проверка ввода на всех концах

### Service Mesh безопасность
- mTLS шифрование между всеми сервисами
- Проверка JWT токенов на уровне sidecar
- Политики авторизации между сервисами

### Безопасность событий
- Подпись событий для проверки целостности
- Проверка источника событий
- Защита от повторного воспроизведения событий

### Защита данных
- TLS 1.3 для всех коммуникаций
- Шифрование при хранении для конфиденциальных данных
- Минимизация и маскировка персональных данных
- Безопасное управление сессиями

## 📱 Мобильные функции

### Флаги функций
- Удаленная конфигурация с Firebase Remote Config
- Фреймворк A/B тестирования для экспериментов
- Постепенные запуски новых функций

### Поддержка офлайн
- Локальная база данных с автоматической синхронизацией
- Подход "сначала кэш" для улучшения UX
- Разрешение конфликтов для офлайн изменений
- SyncManager для управления синхронизацией данных

### Выбор города (Web)
- CitySelectorWidget для выбора города вместо геолокации
- Поиск городов через Nominatim OpenStreetMap API
- Список популярных городов России (Москва, СПб, Казань и др.)
- Автоматическое обновление рекомендаций с учётом погоды в выбранном городе

### Требования к платформам
- **Android**: API уровень 23+ (Android 6.0+)
- **iOS**: iOS 14.0+
- **Web**: Современные браузеры с поддержкой Flutter Web

### SyncManager - Синхронизация данных
- **Архитектура синхронизации**: Управляет синхронизацией всех данных приложения, включая пользовательские настройки, элементы гардероба, рекомендации и отзывы
- **Как работает**: Мониторит состояние подключения и автоматически синхронизирует данные при восстановлении соединения; также запускает периодическую синхронизацию каждые 5 минут
- **Какие данные синхронизируются**:
  - Пользовательские настройки и предпочтения
  - Элементы гардероба (добавление, обновление, удаление)
  - Рекомендации и история просмотров
  - Отзывы и рейтинги
  - Оффлайн изменения из очереди синхронизации
- **Обработка offline/online состояний**:
  - При потере соединения продолжает работать в автономном режиме
  - При восстановлении соединения автоматически запускает синхронизацию
  - Использует очередь синхронизации для отложенных изменений
- **Отслеживание прогресса синхронизации**:
  - Отслеживает прогресс для каждой операции синхронизации
  - Предоставляет информацию о текущей операции
  - Позволяет отслеживать статус синхронизации в реальном времени
