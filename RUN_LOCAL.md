# Запуск проекта OutfitStyle с ограничением ресурсов

Для запуска проекта с ограниченным использованием ресурсов (чтобы не перегружать ваш ПК):

## Подготовка

1. Убедитесь, что Docker Desktop запущен
2. Убедитесь, что у вас есть хотя бы 4 ГБ свободной оперативной памяти

## Запуск

### Вариант 1: Использование скрипта (рекомендуется)
Запустите файл `start-limited.bat` от имени администратора

### Вариант 2: Ручной запуск
Откройте командную строку в директории проекта и выполните:

```bash
docker-compose -f docker-compose.dev.yml up --build
```

## Особенности конфигурации

Этот конфигурационный файл отличается от стандартного тем, что:

- Ограничивает использование CPU и RAM для каждого сервиса
- Уменьшает количество соединений с базой данных
- Уменьшает частоту запросов
- Отключает некоторые ресурсоемкие функции
- Уменьшает уровень логирования

## Остановка

Для остановки проекта нажмите `Ctrl+C` в окне терминала

## Проверка ресурсов

Вы можете проверить использование ресурсов Docker командой:
```bash
docker stats
```

## Адреса сервисов

- API: http://localhost:8080
- PostgreSQL: localhost:5432
- Redis: localhost:6379
- ML Service: http://localhost:5000
