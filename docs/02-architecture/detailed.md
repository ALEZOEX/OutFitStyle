# Архитектура OutfitStyle

## Простыми словами

OutfitStyle помогает подбирать одежду по погоде. Вот как это работает:

```
Приложение (Flutter)
       │
       │ Запрос: "Что надеть сегодня?"
       ▼
Backend (Go) ───► Погода (OpenWeatherMap)
       │              │
       │              ▼
       │         Температура: +15°C
       │         Дождь: да
       │
       ▼
База данных: "У пользователя есть джинсы и футболка"
       │
       ▼
ML модель: "Добавь куртку, потому что дождь"
       │
       ▼
Ответ: "Надень джинсы, футболку и куртку"
```

## Основные компоненты

**1. Flutter приложение**
- Показывает погоду и рекомендации
- Позволяет добавить вещи в гардероб
- Работает на телефоне и в браузере

**2. Backend (Go)**
- Принимает запросы от приложения
- Проверяет логин/пароль
- Запрашивает погоду
- Отдаёт рекомендации

**3. База данных (PostgreSQL)**
- Хранит пользователей и их вещи
- Хранит рекомендации
- Хранит историю просмотров

**4. ML сервис (Python + CatBoost)**
- Анализирует что носить в такую погоду
- Учитывает предпочтения пользователя
- Предлагает похожие вещи

**5. Кэш (Redis)**
- Быстрый доступ к частым запросам
- Хранит сессии пользователей

## Как работает рекомендация

1. Пользователь открывает приложение
2. Backend узнаёт погоду через API
3. Backend спрашивает у ML: "Что надеть при +15°C и дожде?"
4. ML смотрит гардероб пользователя
5. ML предлагает: джинсы + футболка + куртка
6. Приложение показывает рекомендацию

## Технологии

| Часть | Технология | Зачем |
|-------|------------|-------|
| Приложение | Flutter | Кроссплатформенный UI |
| Backend | Go | Быстрый API сервер |
| ML | Python + CatBoost | Умные рекомендации |
| База | PostgreSQL | Надёжное хранение |
| Кэш | Redis | Быстрый доступ |
