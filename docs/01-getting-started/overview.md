# Обзор проекта OutfitStyle

## 📱 Что такое OutfitStyle?

OutfitStyle — это AI-powered платформа для умных рекомендаций одежды на основе погоды и предпочтений пользователя.

### Основные возможности

1. **Умный гардероб** — цифровизация вашей одежды
2. **ML рекомендации** — подбор outfit'ов на основе CatBoost модели
3. **Погодная интеграция** — учёт текущих и прогнозируемых условий
4. **Персонализация** — обучение на предпочтениях пользователя

## 📦 Основные модули

### 1. Аутентификация и авторизация

- Google Sign-In
- Email/пароль
- JWT токены (access + refresh)
- Rate limiting

### 2. Гардероб (Wardrobe)

- CRUD операций с вещами
- Категоризация (12 категорий)
- Загрузка изображений
- Поиск и фильтрация

### 3. Рекомендации (Recommendations)

- Retrieval модель (поиск кандидатов)
- Ranking модель (CatBoost ранжирование)
- Учёт погоды
- Персонализация

### 4. Подписки

- Free план
- Premium (99₽/мес)
- Premium Plus (199₽/мес)
- YooKassa интеграция
