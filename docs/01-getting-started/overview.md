# О проекте OutfitStyle

## Что это такое?

OutfitStyle — это приложение, которое помогает выбрать одежду по погоде.

**Пример:**
- На улице +10°C и дождь
- Приложение подскажет: надень куртку, джинсы и возьми зонт

## Зачем это нужно?

Многие люди утром смотрят в окно и не знают что надеть. Особенно сложно:
- Весной и осенью (переменчивая погода)
- Зимой (слишком холодно или тепло)
- Когда идёшь в школу/университет/на работу

OutfitStyle решает эту проблему!

## Как это работает?

1. **Добавь вещи в гардероб**
   - Сфоткай свою одежду
   - Или выбери из каталога
   
2. **Приложение узнаёт погоду**
   - Через интернет (OpenWeatherMap API)
   - По твоему местоположению

3. **Получи рекомендацию**
   - ML модель подбирает outfit
   - Учитывает температуру, дождь, ветер
   - Учитывает твой стиль

## Что внутри?

**Приложение умеет:**
- 🔐 Регистрация и вход через Google
- 👕 Гардероб (12 категорий вещей)
- 🌤️ Рекомендации по погоде
- ⭐ Оценка рекомендаций (нравится / не нравится)
- 💰 Подписки (Free, Premium, Pro)

**Технологии:**
- Flutter — приложение для телефона и веба
- Go — быстрый backend
- Python + CatBoost — умные рекомендации
- PostgreSQL — база данных
- Redis — кэш для скорости
