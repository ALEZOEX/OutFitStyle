# Использование изображений в уведомлениях и других частях приложения

## Общие положения

В текущей архитектуре предусмотрена возможность использования изображений в уведомлениях и других частях приложения, но пока реализация ограничена. В настоящее время можно использовать эмодзи или простой текст.

## Уведомления

В структуре `CreateNotificationParams` есть поле `ImageURL *string`, которое позволяет добавлять изображения к уведомлениям. Однако:

- Пока не реализована система хранения и доставки изображений для уведомлений
- Не определены требования к размеру, формату и качеству изображений
- Не протестирована доставка изображений через push-уведомления

## Возможные улучшения

### 1. Система хранения изображений
- Интеграция с S3-совместимым хранилищем
- Автоматическое создание миниатюр
- Оптимизация размера изображений для мобильных устройств

### 2. Уведомления с изображениями
- Поддержка изображений в push-уведомлениях
- Резервные варианты для случаев, когда изображения не поддерживаются
- Кеширование изображений уведомлений

### 3. Другие части приложения
- Профили пользователей
- Элементы одежды
- Рекомендации
- Достижения
- Каталоги

## Технические требования

### Форматы
- Основной: JPEG, PNG
- Для иконок: WebP, SVG
- Анимированные: GIF (ограниченно)

### Размеры
- Уведомления: до 250KB
- Профили: до 2MB
- Каталоги: до 5MB

### Безопасность
- Проверка MIME-типов
- Санитизация изображений
- Антивирусная проверка

## План реализации

1. **Сейчас**: Использовать эмодзи и текст
2. **Позже**: Добавить поддержку простых изображений
3. **В будущем**: Полноценная система управления медиафайлами

## Заметки по UX

- Не перегружать уведомления изображениями
- Обеспечить доступность для пользователей с ограниченными возможностями
- Предусмотреть опции отключения изображений в уведомлениях
