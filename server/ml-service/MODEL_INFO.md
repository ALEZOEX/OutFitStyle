# Информация о модели

## Архитектура

ML-сервис для рекомендации и генерации комплектов одежды. Включает:

- `/api/rank` - ранжирование кандидатов одежды
- `/api/v1/rank` - устаревший эндпоинт (теперь тоже использует v2 фичи)
- `/api/outfits` - генерация комплектов одежды

## Модель

Модель представляет собой CatBoostClassifier, обученный на `data/raw/training_data.csv`. Архитектура:

- Формат: `catboost_cbm`
- Тип: `classifier` (в будущем будет `ranker`)
- Признаки: категориальные и числовые признаки одежды, погоды и профиля пользователя

## Обновление фичей

С версии v2 используется `build_feature_frame_v2` и `normalize_item` для согласованной обработки признаков между тренировкой и инференсом.

## Обучение модели

Для обучения новой модели:

```bash
python train/train_classifier.py --data-path data/raw/training_data.csv --out-dir models
```

## Артефакты модели

- `models/model.cbm` - бинарная модель CatBoost
- `models/model.pkl` - манифест с метаданными
- `models/metadata.json` - дополнительные метаданные

> **Важно**: Файлы моделей не включены в Git из-за размера. Они генерируются при обучении.
