# Istio Service Mesh для OutfitStyle

## Обзор

Istio Service Mesh обеспечивает безопасное, надежное и масштабируемое взаимодействие между микросервисами в OutfitStyle.

## Компоненты

### Gateway
- Обрабатывает внешний трафик в кластер
- Направляет запросы к соответствующим сервисам

### VirtualService
- Определяет правила маршрутизации трафика
- Позволяет реализовать A/B тестирование и канареечные релизы

### DestinationRule
- Определяет политики подключения и обнаружения выбросов
- Управляет балансировкой нагрузки между сервисами

### ServiceEntry
- Расширяет Istio Service Discovery
- Позволяет взаимодействовать с внешними сервисами

## Архитектура

```
[Клиент] -> [Istio Ingress Gateway] -> [VirtualService] -> [DestinationRule] -> [Сервисы]
```

## Политики безопасности

- mTLS между сервисами по умолчанию
- Правила авторизации на уровне сервисов
- Централизованное управление политиками доступа

## Мониторинг

- Метрики запросов, задержек и ошибок
- Распределенная трассировка запросов
- Визуализация топологии сервисов
